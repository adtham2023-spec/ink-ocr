# 常见问题

## 需要付费 API 或注册账号吗？

不需要。运行已打包版本时，OCR、PDF 渲染和繁转简都在本机完成。安装源码依赖时，需要先下载开源软件包。

## 横着的 PDF 页怎么识别？能改行序和换引擎吗？

选中页面，先用顶部左／右转按钮旋正，再点“重新识别当前页”。顶部可选 RapidOCR 或 Tesseract；切换不会自动覆盖现有文字。识别结果可以拖拽整行改变阅读顺序，也可新增、删除、合并相邻行。页面结构操作与重识别可用“撤销”恢复，最多 8 次。

Windows 发行版已含 Tesseract 及三份语言模型。源码用户需先运行 `python scripts/fetch_tessdata.py` 准备模型，后续可离线使用。两个引擎效果因字体和版面而异，分数也不能直接横向比较。

## 为什么看起来识别正确的行分数不高，错字反而分数很高？

分数是模型的置信度，不是人工核验的正确率。阈值帮助安排校对顺序，但不能代替阅读原文。人工修改后保留原始分数，不重新评分。

## 只校对低分行后，高分文字去哪了？

只是在逐行列表里隐藏。全文、复制、TXT 导出及校对进度仍保留全部文字。关闭“只校对低分行”就能重新看到全部行。

## 保存之后能换电脑继续吗？

进度引用原始文件路径，不会自动把整本 PDF 打包进去。当前版本适合保留原文件位置后分次继续校对；迁移电脑或移动文件需要同时保留可用的原路径。尚未提供图形化的原文件重新定位功能。

## 可以导出 Word、EPUB 或可搜索 PDF 吗？

当前输出是 TXT 和 `.inkocr` 校对进度，尚未提供这些格式的排版或文字层导出。

## 能处理繁体、竖排或两页摊开的书吗？

可以导入图片，但现有识别模型主要面向常见中英文印刷体。繁体生僻字、竖排、双页、多栏和复杂表格效果可能不足，需要人工复核或预处理；不能保证阅读顺序正确。

## 为什么有些行提示没有原图坐标？

通常是全文中新增了文字，或合并／拆分了原来的行。程序无法可靠对应时会去掉坐标，避免对到错误原文。文字仍可以保存和导出。

## 双击 EXE 报 QtCore 或 DLL 错误怎么办？

请先确认 ZIP 已完整解压，EXE 与 `_internal` 仍在同一文件夹。不要只复制 EXE。源码运行时请使用 Python 3.12 和仓库提供的依赖版本，尤其是 PySide6 6.8.3；避免混装不同版本的 Qt 组件。

## 运行识别时可以立即退出吗？

停止需要等当前页完成。可以先点“停止”，待识别任务结束后再关闭。建议在长任务前保存进度，以便自动保留已完成页。
